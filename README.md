# AbVoice Local

喋った内容を文字にして、カーソルのある場所に入れる Mac のアプリです。
メール・チャット・メモなど、文字を入力できる場所ならどこでも使えます。

**文字起こしはこの Mac の中で行います。音声は外に出ません。**

## 動く環境

- Apple シリコン（M1 / M2 / M3 / M4 …）の Mac。Intel の Mac では動きません
- macOS 14 以上（喋っている間に文字を出す「速報」だけは macOS 26 以上）
- 空き容量 1GB 以上（文字起こしモデルの保存に使います）

## 入れ方

1. [Releases](https://github.com/abgata20000/abvoice/releases) から、いちばん新しい `AbVoice-Local-x.y.z.dmg` をダウンロードします
2. ダウンロードした `.dmg` を開き、`AbVoice Local` を `Applications` フォルダにドラッグします
3. アプリケーションフォルダから `AbVoice Local` を開きます

## 最初の設定

初めて開くと、設定の案内が出ます。上から順に進めれば 3 分ほどで終わります。

| 手順                   | やること                                                                                                 |
| ---------------------- | -------------------------------------------------------------------------------------------------------- |
| マイクの許可           | 「マイクを許可する」を押し、出てきた確認で「許可」を押します                                             |
| アクセシビリティの許可 | 「システム設定を開く」を押し、一覧の「AbVoice Local」をオンにします。許可されると自動で次へ進みます      |
| 文字起こしモデル       | 「取得する」を押します。標準で約 626MB です。取得したあと、最初の 1 回だけ準備に数分かかります           |
| ホットキー             | 口述に使うキーを決めます。迷ったら「⌃⌥Space を使う」を押してください                                     |
| 試してみる             | 入力欄をクリックしてからホットキーを押し、喋って、もう一度ホットキーを押します。文字が入れば準備完了です |

モデルの取得は裏で続くので、取得が終わる前に次の手順へ進んでかまいません。

## 使い方

1. 文字を入れたい場所をクリックします
2. ホットキーを押して、喋ります
3. もう一度ホットキーを押すと、文字になって入ります

- ホットキーを**押したまま喋って離す**と、離したところで止まります
- `Escape` を押すと、録音を捨てます（何も入りません）
- 入れた文字は「履歴」に残ります。あとからコピーや、もう一度入れることができます

### 音声コマンド（ウィンドウを動かす）

コマンド用のホットキー（初期設定は `⌃⌥⌘Space`）を**押したまま**喋り、離すと実行します。

- 「Slack を左半分」「Chrome を右半分」「最大化」「Finder を開いて」のように話します
- アプリの呼び名は「コマンド」の画面で足せます
- 使わない場合は「コマンド」の画面でオフにできます

## もっと良くする

### 辞書（おすすめ）

聞き間違いやすい言葉を登録すると、その表記に直して入れます。
**まず、自分の名前と、よく使う製品名を 5 個ほど入れてみてください。**

- 「辞書」の画面で「追加」を押し、正しい表記と、間違えて出てきた表記（誤変換）を入れます
- 次の発話から、誤変換が正しい表記に置き換わります
- 辞書は「書き出し」で JSON ファイルにして、人に渡せます（もらった人は「読み込み」で取り込めます）

設定の「辞書の語をヒントに渡す」をオンにすると、文字起こしの段階から聞き取りやすくなります。
ただし、渡す語が多いほど文字になるまでが遅くなります（10 語で約 0.5 秒）。確実に直したい語は、誤変換として登録してください。

### Ollama で整形する（任意）

[Ollama](https://ollama.com/download) を入れると、「えーと」などの言い淀みを除いたり、句読点を補ったりできます。
Ollama も、この Mac の中で動きます。

1. Ollama を入れて起動します
2. AbVoice Local の「設定 → 整形」で「調べ直す」を押します
3. 「モデルを取得」を押します（初期設定は `gemma3:4b`。約 3GB）

Ollama が動いていないときは、整形せずにそのまま入れます。

### OpenAI を使う（任意）

OpenAI の API キーを持っている人は、文字起こしや整形を OpenAI に切り替えられます。

1. 「設定 → OpenAI」で API キーを登録します
2. 「設定 → 文字起こし」または「設定 → 整形」で OpenAI を選びます

**OpenAI を選んだときだけ、音声やテキストが OpenAI に送られ、料金がかかります。** キーを登録しただけでは何も送りません。

## 音声の扱い

- **既定の設定では、音声もテキストもこの Mac の外に出ません**
- インターネットに接続するのは、次のときだけです
  - 文字起こしモデルの取得（初回と、モデルを切り替えたとき）
  - 設定で OpenAI を選んだとき（選んだものだけを送ります）
- 「この Mac の中」で文字起こしする設定のときは、失敗しても OpenAI に切り替えることはありません
- **録音は保存しません。** 文字にしたら捨てます（失敗したときだけ、やり直し用に直近の 1 件をメモリに持ちます。アプリを終了すると消えます）
- 履歴と辞書は、この Mac の次の場所にだけ保存します

```
~/Library/Application Support/jp.abgata.abvoice.local/
  history.jsonl     履歴（1 行 1 件）
  dictionary.json   辞書
  Models/           文字起こしモデル
```

- 履歴は「設定 → 履歴」で、残さないようにしたり、残す期間（30 日 / 90 日 / 無期限）を選んだりできます

## 困ったとき

| 困っていること                   | 試すこと                                                                                                                  |
| -------------------------------- | ------------------------------------------------------------------------------------------------------------------------- |
| ホットキーを押しても何も起きない | 「設定 → 権限」でアクセシビリティが許可されているか確かめ、「再接続」を押します                                           |
| 「声が入っていません」と出る     | 「設定 → マイク」で使うマイクを選び、「マイクをテスト」で拾えているか確かめます（蓋を閉じていると内蔵マイクは使えません） |
| 「モデルを取得中です」と出る     | 取得と準備が終わるまで待ちます。状態はウィンドウ左下に出ます                                                              |
| 文字は出るのに入らない           | 入れたい場所をクリックしてから録音します。入らないアプリでは「設定 → 挿入」を「直接入力」にすると入ることがあります       |
| 他のアプリとホットキーがぶつかる | 「設定 → ホットキー」で「キーを記録」を押し、別のキーを押します                                                           |
| 何をしているか分からない         | 「設定」の一番下の「最近の動作ログ」に、理由が出ていないか見ます                                                          |
| 権限を付け直したい               | システム設定の「プライバシーとセキュリティ」で AbVoice Local をいったんオフにしてからオンにし、アプリを開き直します       |

パスワードの入力欄では、安全のため録音も入力もしません。

### 上級者向け: Caps Lock をホットキーにする

キーのリマップができる [Karabiner-Elements](https://karabiner-elements.pqrs.org/) で Caps Lock を `F18` に割り当て、
「設定 → ホットキー → キーを記録」で Caps Lock を押すと、Caps Lock 1 つで録音できるようになります。

## 新しい版に更新する

新しい `.dmg` を開き、`Applications` に上書きでドラッグします。
設定・辞書・履歴・取得済みのモデルはそのまま残り、許可を付け直す必要もありません。

## 消し方

1. メニューバーのマイクのアイコンから「AbVoice Local を終了」を選びます
2. `Applications` から `AbVoice Local` をゴミ箱に入れます
3. 履歴・辞書・モデルも消すときは、次のフォルダをゴミ箱に入れます

```
~/Library/Application Support/jp.abgata.abvoice.local/
```

4. OpenAI のキーを登録していた場合は、「キーチェーンアクセス」で `jp.abgata.abvoice.local` を検索して削除します
