# AbVoice Local の全体像

喋った内容を、この Mac の中で文字にして、カーソルの位置に入れるアプリ。
使い方は [README](../README.md)、ビルドとリリースは [DEVELOPMENT](../DEVELOPMENT.md) を見る。

## 録音から挿入まで

```
ホットキー（HotkeyMonitor）
  → 録音（AudioRecorder: 16kHz / mono / 16bit。ディスクには書かない）
  → 文字起こし（TranscriptionService）
       この Mac の中: WhisperEngine（WhisperKit）  ← 既定
       OpenAI: 本人が選んだときだけ。届かなければこの Mac の中に落とす
  → ハルシネーションの判定（HallucinationFilter）
  → 整形
       1. フィラー除去（FillerRemover。正規表現）
       2. LLM（FormatService。Ollama / OpenAI / なし のうち選んだものだけ）
       3. 辞書の置き換え（LocalDictionaryStore。必ず LLM の後）
       4. 文の区切りで改行（SentenceWrapper。任意）
  → 挿入（TextInserter。クリップボード退避 → Cmd+V → 復元）
  → 履歴に追記（LocalHistoryStore）
```

全体の流れは `VoiceCoordinator` が束ねている。音声コマンドは文字起こしまで同じで、
その後 `CommandParser`（パターン照合）→ 外れたら LLM（整形と同じプロバイダ）→ `CommandExecutor` に進む。

## 外への通信

| いつ                | 宛先                       | 送るもの             |
| ------------------- | -------------------------- | -------------------- |
| モデルの取得        | Hugging Face               | なし（取得するだけ） |
| 文字起こしで OpenAI | api.openai.com             | 録音した音声         |
| 整形で OpenAI       | api.openai.com             | 文字起こしの結果     |
| 整形で Ollama       | localhost（この Mac の中） | 文字起こしの結果     |

既定の設定では、モデルの取得以外に外へ出る通信は無い。
ATS は `NSAllowsLocalNetworking` だけを許している（平文 HTTP は localhost にしか届かない）。

## 保存しているもの

すべて `~/Library/Application Support/jp.abgata.abvoice.local/` の下。

| ファイル            | 中身                                                |
| ------------------- | --------------------------------------------------- |
| `history.jsonl`     | 履歴（1 行 1 件）。保持期間を過ぎた行は起動時に消す |
| `dictionary.json`   | 辞書。書き出し・読み込みと同じ形                    |
| `app-aliases.json`  | 音声コマンド用のアプリの呼び名                      |
| `Models/`           | 文字起こしモデルとトークナイザ                      |
| `abvoice-local.log` | 動作ログ（1MB を超えたら消す）                      |

設定は UserDefaults（`jp.abgata.abvoice.local`）、OpenAI の API キーは Keychain（サービス名も同じ）。

## 文字起こしエンジンの実測（2026-10-14、M3 / メモリ 24GB / macOS 26）

読み上げ音声で測った。実際の声での精度は未確認。

| 音声の長さ | 標準 `626MB` | 標準 + 辞書 9 語 | 軽量 `216MB` | 軽量 + 辞書 9 語 |
| ---------- | ------------ | ---------------- | ------------ | ---------------- |
| 2〜3 秒    | 0.8〜0.9 秒  | 1.4 秒           | 0.5〜0.6 秒  | 2.0 秒           |
| 5〜7 秒    | 1.0〜1.4 秒  | 1.7〜2.1 秒      | 1.1〜1.3 秒  | 2.3〜3.4 秒      |
| 20 秒      | 2.6〜3.1 秒  | 3.4〜3.8 秒      | 3.2 秒       | 4.6 秒           |

- 同じ条件でも 2 倍ほど揺れることがある（連続で流すとエンコードが遅くなる回があった。原因は特定していない）
- 常駐メモリ: 標準 約 1.0GB / 軽量 約 0.5GB。アクティビティモニタの値には Neural Engine 側（標準で約 880MB）が含まれない。
  外から `footprint <pid>` で測ること
- 取得した直後の 1 回目の読み込みは、Core ML の最適化で 標準 80〜184 秒 / 軽量 25〜46 秒。2 回目以降は 1 秒前後
- 精度: 軽量は「見積もり → 三つ森」「固有名詞 → 古有名詞」のように崩れることがある。既定は標準
- 計算ユニットを GPU にすると使えない（メモリ 3GB、1 本に 20 秒以上）。既定の Neural Engine のまま使う
- `large-v3-v20240930_turbo_632MB` も試したが、速度は標準と同程度で初回の読み込みが 273 秒かかった

## WhisperKit の癖と対処

| 癖                                                                                       | 対処（`WhisperEngine`）                                                     |
| ---------------------------------------------------------------------------------------- | --------------------------------------------------------------------------- |
| 標準モデルにプロンプトを渡すと、直後に終了トークンを出して結果が空になる（10 本中 6 本） | 本文の最初の 1 トークンだけ終了を選ばせない `LogitsFiltering` を付ける      |
| プロンプトを渡すと、語数に比例して遅くなる（事前計算のキャッシュが使えない）             | 辞書の語を渡すかは設定で選ぶ。既定は渡さない                                |
| どの語にプロンプトが効くかは、渡す語の組み合わせで変わる                                 | 確実に直したい語は辞書の置き換えに入れる（README にも書いた）               |
| 30 秒を超える録音をタイムスタンプなしで処理すると、区切りで言葉が落ちる                  | 25 秒を超えたらタイムスタンプありにし、`skipSpecialTokens` を付ける         |
| 言語確率は `transcribe` の結果に入らない。`detectLanguage` はエンコーダをもう 1 回回す   | 3 秒以下の録音だけ先に調べ、日本語でなければ文字起こしをしない              |
| 既定のやり直し回数（5 回）だと、無音 + プロンプトで 30 秒以上やり直す                    | `temperatureFallbackCount` を 1 にする                                      |
| 取得済みでも `download` を呼ぶと問い合わせに 4 秒かかり、オフラインで起動できない        | 取得が終わった印のファイルを置き、あれば `modelFolder` を直接渡して読み込む |
| 依存ライブラリのリソース（`*.bundle`）を `Contents/Resources/` から探し、無ければ落ちる  | `build.sh` で `.app` に入れる                                               |
